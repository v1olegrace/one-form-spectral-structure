## The bound attempted

For decay kinematics, the Feynman-parameter form of each ordering has
Delta = 1 - lambda^2 R(x), with s = lambda^2 and, at s = 1,
R(x) = x0 x3 + s_a x0 x2 + s_b x1 x3 (code: `_ordering_values`). Here s_a and
s_b are two Dalitz invariants, so s_a + s_b <= 1.

**Lemma.** 0 <= R(x) <= 1/4 on the simplex.

*Proof.* With t = s_a, R <= x0 x3 + t x0 x2 + (1 - t) x1 x3. This is at most
(x0 + (1-t) x1)(x3 + t x2), the product minus t(1-t) x1 x2. By AM-GM that
product is at most ((x0 + x1 + x2 + x3)/2)^2 = 1/4. Every term is
non-negative.

The tails of 1/Delta^2, 1/Delta and log Delta after order K are then
geometric with ratio at most s/4. Each tail is bounded by an explicit
multiple of int R^n0 dx, which is an exact polynomial integral.

The numerators are Dirac traces with spatial unit polarizations
(||e-slash|| = 1). With K-slash bounded by |K^0| + |K|, a slot of degree one
has norm at most 4 at s = 1, and |Tr M| <= 4 ||M||. This gives:
- |N0_jd| <= 4 C(4,jd) 4^jd;
- |N2_jd| <= 96 C(2,jd) 4^jd;
- |T4| <= 192.

The six orderings are summed in absolute value. With the density written
as rho = (1/4608) int sum_pol |A|^2, Cauchy-Schwarz gives
|rho - rho_K| <= 2 sqrt(rho_K eps) + eps, where eps = E^2/384.

## Prediction, written before computing

The bound ignores the gauge cancellations among the six orderings and
inside each Feynman integral. So it will exceed the true remainder by three
to four orders of magnitude. It will control the truncation only for s below
about 0.3 m^2, which carries roughly 70% of Phi_3gamma at r_Gamma. The
implied radius uncertainty will be far above 0.01/m. The rule then stops
R9.

## Two rigorous refinements

- **Convexity.** R is linear in t = s_a, and decreasing s_b only lowers it,
  so int R^n <= int (x0 x3 + t x0 x2 + (1-t) x1 x3)^n. This is convex in t,
  so its maximum is at t = 0 or t = 1. Both endpoints give
  I*(n) = int x3^n (x0+x1)^n = n!(n+1)!/(2n+3)!, from the Dirichlet(1,2,1)
  marginal. The closed form was checked against brute-force Dirichlet
  moments.
- **Slot norm.** At s = 1 every K_i^0 lies in [-1, 0] and |K_i| <= 1/2.
  Hence |v_j^0| <= 1 and |v_j| <= 1, so ||v-slash_j|| <= 2. This gives
  B0[jd] = 4 C(4,jd) 2^jd and B2[jd] = 96 C(2,jd) 2^jd.

The bound on |drho|/rho becomes:

| s | K = 18 | K = 26 |
|---|---|---|
| 0.5 | 7.2e-4 | 1.5e-7 |
| 0.75 | 1.7e-2 | 1.8e-5 |
| 1.0 | 0.18 | 5.7e-4 |
| 1.25 | 1.35 | 8.5e-3 |
| 1.5 | 11 | 8.2e-2 |
| 2.0 | 930 | 5.5 |

## Checks against the code (`tests/test_three_photon_envelope.py`)

Every constant of the bound was checked against the code's own quantities.
The checks ran at five Dalitz points, including the collinear pairs y3 = 0
and y1 = 0 and a soft photon, for all six orderings:

- R lies in [0, 1/4] at every node of simplex_rule(14).
- The quadrature of R^n, exact up to n = 12, is below I*(n) for n = 8..12.
- Slot norms are at most 2.
- |N0|, |N2| and |T4| are below their bounds.
- The closed form of I*(n) equals the Dirichlet moments.

The unexpanded amplitude minus its truncation, at K = 8 and 12 and
s = 0.5, 0.75, 1.0 and 1.5, stays below the envelope everywhere. The ratio
envelope/remainder is 4000 to 5600, almost independent of s and K. So the
bound has the right geometric rate, s/4 per order, and a crude constant. The
crude constant is what the first prediction expected; the failure radius
it predicted was wrong.

With K = 18 the envelope holds up to about 1.1 m^2. Above that, the
leading-order profile at r_Gamma has about 0.3% of Phi_3gamma, counting the
density enhancement. With K = 26 it holds to about 1.8 m^2, and the share
above is about 1e-4. The stopping rule is passed. The bound is on
|rho - rho_K|. The six-term model also differs from rho_K by cross terms
beyond s^9, which have to be computed from the same amplitude coefficients.
