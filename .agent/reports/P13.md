## Findings

**First clean-room run (earlier snapshot).** Every command passed. Byte drift
appeared in eight rendered figures (`output/figures/*.png`, `*.svg`): the
matplotlib version and layout coordinates. It also appeared in
`output/data/extended_verification.json`: the recorded package versions, and
two QUADPACK error estimates that differ in the 9th digit. No scientific value
changed.

The CI guard added in P4 covered both, so it would have failed on the first
push. It was narrowed on this evidence; see the P4 addendum. In the final run
the drift is the same and confined to the excluded files, and every guard
exits 0.

**Test count 469 versus 466.** `test_text_hygiene` runs once per tracked
file. Three new candidate files are untracked in the working tree but tracked
in the snapshot: the two reports and `scripts/build_claim_graph.py`. A commit
of the candidate set therefore has 469 tests.

**PDF.** The canonical paper builds in the clean room. In the working tree,
`reproducibility/canonical_pdf_qa.py` gives PASS: v0.5.4, 16 pages, fonts
Type0/Type1, no issues. The changed pages were inspected as images.
`paper/professor_brief.tex` builds to 6 pages, with two benign package
warnings: inputenc is ignored under a UTF-8 engine, and shell escape is
disabled.
