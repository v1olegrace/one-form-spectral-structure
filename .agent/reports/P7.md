## Part B: predictions recorded before any computation

B1. Exterior lemma. For a positive, normalised radial source supported in
|u| <= a, the linear profile at r > a is exactly int e^{-rx} F(x) dnu(x),
F(x) = int rho(u) sinh(xu)/(xu) d^3u, with 1 <= F <= sinh(xa)/(xa). So the
exterior profile is completely monotone with the same support edge, and the
effective-mass bound Gamma >= M_* holds for a finite probe. Prediction: an
independent momentum-space evaluation for a uniform ball with the one-loop
Dirac measure agrees with the F-weighted Laplace form at r > a.

B2. Gaussian source with the actual one-loop Dirac measure (replacing the
massive-atom placeholder). Prediction: for R = 10/m, q = 0.3, the linear
term outside the core is dominated by the local Uehling term
(4 alpha/15) r lap(rho_R) (to about 10-15%), set by the source's Gaussian
tail; the e^{-2mr} threshold tail never dominates before the crossover; the
derivative-expansion estimate x^7 (4x^2-6) e^{-x^2} = alpha q^2/(6 sqrt(pi) R^2)
gives r_x ~ 5.6 R = 56/m. The spectral and momentum routes should agree to
better than 1e-10 relative at r <= 3R.

B3. Compact uniform ball, a = 10/m, q = e (q_W = 1), Dirac measure, exterior
first-order sum int e^{-rx} F dnu - c q^2/(pi^2 r^6). Prediction:
r_x ~ 20-21/m, i.e. about 10-11/m from the surface, close to the
point-source 11.57/m; beyond it the sum is negative.

B4. Two-sided energy bound for any source by convex duality: trial field
D_0 in the primal and phi_0 in the dual give
0 <= U_c - U_0 + c int|D_0|^4 <= 8 c^2 int|D_0|^6 without radial symmetry.
Prediction: an independent discrete convex solve satisfies it; for the
interaction V(r) the bound does not decay, so it controls the O(c)
interaction only for r below a window r_V, of order hundreds of R for the
weak-field Gaussian example (R=10, q=0.3).
