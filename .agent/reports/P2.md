# P2 — RPA numerical stability and diagnostics

Date: 2026-10-23. Scope: binary64 one-loop Dirac model; no full-QED claim.

## Prediction recorded before changes

Near `b=4.000000001`, cancellation in the general closed form and in
`sqrt(1-4/s)` makes an apparently resolved atom inaccurate. A stable
threshold coordinate `v=sqrt((s-4)/s)` with `v=v_b*u` removes this subtraction.
Scaling the polarization integral before quadrature should retain relative
precision when its absolute size is very small. A logarithmic endpoint term
plus a smooth residual should stabilize the atom integral on narrow support.

An independent mpmath reference must accept the identical stored binary64
cutoff/coupling, rather than silently recompute an ideal coupling ratio.
Expected outcome: corrected atom agrees with the independently transformed
60/90-digit reference, or the affected path explicitly refuses with
`UNRESOLVED`. Large disagreement of derivative/weight routes must never leave
`RESOLVED`; the existing `b=1e6` tolerances will remain unchanged.

All numerical outcomes remain `CHECKED`, not `CERTIFIED`. The exact critical
regime remains undecidable from a numerical coupling alone.
